# CodeAlpha_UnemploymentAnalysis

# Unemployment Analysis with Python 📊

## Project Overview
Python-based analysis of unemployment trends in India with COVID-19
impact study using data visualization techniques.

## Dataset Information
- Total Records: 768
- States Covered: 28
- Date Range: May 2019 to June 2020
- Source: Kaggle — Unemployment in India

## Features in Dataset
- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area (Rural/Urban)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Correlation Analysis
5. Unemployment Trend Visualization
6. COVID-19 Impact Analysis
7. Rural vs Urban Comparison
8. Labour Participation Rate Analysis
9. State-wise Analysis
10. Monthly Heatmap
11. Key Insights Summary

## Visualizations Created
- Correlation Heatmap
- Overall Unemployment Trend Line Chart
- Pre COVID vs During COVID Box Plot
- Rural vs Urban Unemployment Line Chart
- Labour Participation Rate Line Chart
- Top 10 States Bar Chart
- Monthly Unemployment Heatmap

## Key Insights
- Unemployment nearly doubled during COVID-19 (9.51% → 17.77%)
- COVID-19 caused an increase of 8.26% in unemployment rate
- Tripura had the highest average unemployment rate
- Meghalaya had the lowest average unemployment rate
- Urban areas were more severely impacted than Rural areas
- April-May 2020 saw the peak unemployment during lockdown
- Labour Participation Rate also dropped significantly during COVID

## How to Run
1. Clone this repository
2. Install required libraries:
```bash
pip install pandas numpy matplotlib seaborn
```
3. Open the notebook in Jupyter:
```bash
jupyter notebook unemployment_analysis.ipynb
```
4. Run all cells sequentially
